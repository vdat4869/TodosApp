# Todos App

Ứng dụng web quản lý công việc toàn diện (Full-stack Web Application) phục vụ Portfolio cho vị trí **Java Backend Developer Internship**.

- **Backend:** Java 21 LTS, Spring Boot 3.x, Spring Security & JWT, Spring Data JPA, PostgreSQL, Flyway, Docker.
- **Frontend:** TypeScript, React, Vite, Tailwind CSS, Axios, React Router, i18next.
- **Kiến trúc:** Modular Monolith kết hợp Clean Architecture thực dụng.
